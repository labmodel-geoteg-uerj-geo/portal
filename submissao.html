Submissão de Dados e Produção Científica

Envie metadados científicos e dados geoespaciais para publicação na IDE LABMODEL/GEOTEG/UERJ.

Formatos aceitos nesta etapa:

Vetor: envie um arquivo .zip contendo diretamente: .shp, .shx, .dbf e .prj. Não envie .rar dentro do .zip.

Raster: envie um arquivo .zip contendo um .tif ou .tiff.

Raster com estilo: envie um .zip contendo o .tif/.tiff e, opcionalmente, um arquivo .sld. O Leaflet não lê o raster diretamente; ele exibe o raster via WMS publicado no GeoServer.

Orientação para o arquivo:
Para dados vetoriais, o .zip deve conter diretamente os arquivos do shapefile: .shp, .shx, .dbf e .prj.
Para raster, o .zip deve conter .tif ou .tiff. Se houver estilo, inclua também o .sld.

Os dados enviados passarão por ingestão técnica automática. Dados vetoriais serão importados para o PostGIS. Dados raster serão preparados para publicação via WMS no GeoServer.
